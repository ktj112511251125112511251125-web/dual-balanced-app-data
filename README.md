# DUAL BALANCED App Data

Android 앱에서 읽는 **공개 전용 데이터 저장소**입니다.

`latest.json`은 Private 전략 저장소의 GitHub Actions가 자동으로 갱신합니다.

이 저장소에는 계좌잔고, 보유수량, 평단, 주문수량, 토큰/비밀키를 올리지 않습니다.

## Android raw URL

저장소 주소가 `OWNER/dual-balanced-app-data`인 경우:

`https://raw.githubusercontent.com/OWNER/dual-balanced-app-data/main/latest.json`
